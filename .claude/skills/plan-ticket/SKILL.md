# Plan Ticket

## Purpose

Create a focused implementation plan for one GitHub issue.

## Rules

- Do not modify code.
- Do not create files.
- Do not implement anything.
- Work only on the requested issue.

## Process

1. Read the GitHub issue.
2. Inspect only the relevant parts of the repository.
3. Identify:
   - affected modules
   - existing patterns to follow
   - required changes
   - possible risks
   - testing strategy

## Output

Provide:

# Implementation Plan

## Goal
Short description.

## Files / Modules Affected
List only relevant files.

## Design
Explain the approach.

## Steps
Numbered implementation steps.

## Tests
List required tests.

Keep the answer concise.
